# 02. 匹配视频与日志

> 状态（2026-08-09）：代码已人工检查，尚未跑实际数据实测（脚本头部有 `TODO` 标记）。

## 用途

将录制的游戏视频与对应的操作日志进行时间匹配、对齐裁剪，按对齐后的开始时间命名，
成对输出，供后续训练数据处理使用。本目录包含两个方案：

| 脚本 | 语义 | 适用场景 |
|------|------|----------|
| `main.py` | 单对单·任意开始 | 视频与日志开始时间相互独立，靠时间区间重叠匹配 |
| `main_hotkey.py` | 多对多·录制热键 | 日志先开、必然记录"录制开始快捷键"，按热键时间点对齐 |

两个方案的**日志时段都只按事件记录时间**计算：取日志中首条 / 末条 `[时间戳]` 事件行，
`#` 开头的会话信息头自动跳过、不参与匹配。

---

## 公共约定（两个方案一致）

### 使用参数

```bash
python <脚本>.py <log_dir> <video_dir> <result_dir> [aligned_dir]
```

- `log_dir`：日志 `.txt` 文件所在目录
- `video_dir`：视频文件所在目录
- `result_dir`：输出目录（整段复制的视频 + 汇总 ffmpeg 脚本）
- `aligned_dir`（可选）：对齐输出目录，默认 `result_dir/aligned/`

### 视频文件名格式

`parse_video_start_time` 按优先级尝试以下格式，取第一个匹配；视频时长通过 `ffprobe`
获取，失败时保守按 2 小时估计：

| # | 格式 | 示例 |
|---|------|------|
| 1 | 点号日期 + 短横 + 点号时间（秒+厘秒） | `Yuan Shen 原神 2026.05.28 - 22.09.59.03.mp4` |
| 2 | 点号日期 + 短横 + 点号时间（仅时分/带秒） | `Honkai Star Rail_2026.07.20-00.01.mp4`、`2026.07.26-18.22.mp4` |
| 3 | 短横日期 + 空格 + 短横时间（含秒） | `2026-07-11 00-08-45.mp4` |
| 4 | 短横日期-短横时间-毫秒（无空格） | `Screenrecorder-2026-06-13-13-21-10-525.mp4` |

### 输出说明

1. **对齐裁剪**：对每个匹配对生成 ffmpeg 剪切命令（流复制 `-c copy`，**只生成脚本、不运行**），
   把视频裁到对齐区间；同时把日志裁剪到同一区间（保留 `#` 会话头，并新增一行
   `# 对齐裁剪区间: ...` 记录本次裁剪范围）。
2. **按开始时间命名**：视频与日志以相同的对齐开始时间命名成对输出，例如
   `2026-08-09T02-27-28.505849.mp4` 与 `2026-08-09T02-27-28.505849.txt`，便于后续时间对齐。
3. **汇总脚本**：所有剪切命令写入 `result_dir/cut_ffmpeg.bat`
   （`main_hotkey.py` 为 `cut_ffmpeg_hotkey.bat`），只生成不运行，需人工核对后执行。

### 剪切精度

默认流复制（`-c copy`）：快、无损，但剪切起点可能落在关键帧处，存在约 1~2 秒误差。
如需逐帧精确对齐，可将脚本顶部的 `COPY_CODEC` 改为 `libx264`（重新编码）并相应调整参数。

## 方案一：`main.py`（单对单·任意开始）

1. 提取每个日志最早 / 最晚的事件时间戳，作为日志时段。
2. 解析视频开始时间（文件名）+ 时长（`ffprobe`）。
3. 与任意日志区间**重叠**的视频整段复制到 `result_dir`。
4. 对每个 (视频, 日志) 重叠对取**交集区间**，生成 ffmpeg 剪切命令（只生成不运行），
   同时把日志裁剪到同一区间，按对齐开始时间命名成对输出。

---

## 方案二：`main_hotkey.py`（多对多·录制热键）

适用场景：日志记录一定先打开，因此日志里必然保存了"开始录制"的快捷键事件
（NVIDIA `Alt+F9` / AMD `Ctrl+Shift+E`）。每个热键按下 = 一次录制的开始时间点，
可处理一个日志对应多个视频（多次按热键开始录制）、多个日志 × 多个视频的多对多场景。

1. 扫描日志，检测录制热键时间点（兼容先按修饰键 / 先按触发键的任意顺序；
   组合键补全瞬间记为热键时间）。
2. 解析视频开始时间（文件名）+ 时长（`ffprobe`）。
3. 对每个热键时间点，在 ±2 秒容差内找最近的视频并匹配（一个视频只匹配一次）。
4. 对齐区间：起点 = 热键时间；终点 = `min(同日志下一个热键, 日志结束, 视频结束)`。
5. 生成 ffmpeg 剪切命令（流复制 `-c copy`，只生成不运行），同时把日志裁剪到同一区间，
   按对齐开始时间（热键时间）命名成对输出。
6. 输出未匹配项：有热键没找到视频 / 有视频没匹配到热键。

### 热键配置

如需修改热键，编辑 `main_hotkey.py` 顶部的 `RECORD_HOTKEYS`：
`trigger` 为触发键，`mods` 为所需修饰键组（每组满足其一即可）。
