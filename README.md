# tools4trainAI — AI 训练数据采集与预处理工具集

## 概述

本仓库提供了一套完整的 AI 训练数据采集与预处理工具链，涵盖从游戏操作录制、视频匹配筛选、视频压缩存储、训练数据转码到质量检查的全流程。适用于需要采集游戏画面与操作数据作为 AI 训练素材的场景。

## 模块说明

### 01. 录制鼠标键盘输入

**用途**：在游戏运行的同时，记录玩家的键盘、鼠标和手柄操作，生成带时间戳的日志文件。

| 脚本 | 功能 | 输入 | 输出 |
|------|------|------|------|
| `input_recorder_cross_platform.py` | 使用 pynput 跨平台录制键盘和鼠标事件（按键按下/释放、鼠标点击/移动/滚轮） | 无（实时监听） | `input_YYYYMMDD_HHMMSS.txt` |
| `gamepad_recorder_pygame.py` | 使用 pygame 录制手柄/游戏控制器输入（摇杆、按钮、方向键），支持 Xbox/PS4/PS5 映射 | 无（实时监听） | `gamepad_YYYYMMDD_HHMMSS.txt` |
| `key_waterfall_plot.py` | 将录制的键盘/鼠标日志绘制为瀑布图，直观显示按键时间区间 | 日志文件路径 | matplotlib 图表 |
| `simple_log_reader.py` | 简易的日志分析和回放工具 | 命令参数 | 控制台输出统计信息 |

**依赖**：`pynput>=1.7.6`， `matplotlib>=3.7.0`， `pygame`

---

### 02. 匹配视频与日志

**用途**：将录制的游戏视频与对应的操作日志进行时间匹配，筛选出有完整操作记录的视频片段。

| 脚本 | 功能 | 输入 | 输出 |
|------|------|------|------|
| `main.py` | 解析日志文件的时间区间，匹配视频文件的录制时段，复制有效视频到结果目录 | `python main.py <log_dir> <video_dir> <result_dir>` | 匹配成功的视频文件 |

**匹配逻辑**：
- 从日志 `.txt` 文件中提取最早和最晚的时间戳
- 从视频文件名（格式：`名称 YYYY.MM.DD - HH.MM.SS.cc.mp4`）解析开始时间
- 通过 ffprobe 获取视频时长
- 判断视频时段是否与任意日志区间重叠

**依赖**：FFmpeg/FFprobe（系统安装）

---

### 03. 视频压缩存储

**用途**：对大码率原始视频进行压缩，节省存储空间。码率 ≤ 50Mbps 的直接复制，> 50Mbps 的进行 HEVC 硬件编码压缩。

| 脚本 | 功能 | 输入 | 输出 |
|------|------|------|------|
| `video_processor.py` | 交互式压缩处理：ffprobe 分析码率 → 判断压缩策略 → ffmpeg NVENC H.265 压缩 | 交互式输入源/缓存/目标目录 | 压缩后的视频文件 + 日志文件 |

**压缩参数**：
- 编码器：`hevc_nvenc`（NVIDIA NVENC H.265）
- 目标码率：45Mbps
- 最大码率：70Mbps
- 色深：10bit（p010le）
- 音频：直接复制

**依赖**：FFmpeg/FFprobe（系统安装，需支持 NVENC）

---

### 04. 视频转码成低码率

**用途**：将视频批量转码为 AI 训练可用的低码率格式（高度 640 等比例缩放），自动检测并选用最优硬件编码器。

| 脚本 | 功能 | 输入 | 输出 |
|------|------|------|------|
| `main.py` | 自动检测显卡编码器（NVENC/AMF/QSV/VideoToolbox），批量转码至高度 640，支持 Ctrl+C 中断清理 | 交互式输入源/目标目录 | 转码后的 `.mp4` 文件 |

**编码器检测优先级**：NVIDIA NVENC → AMD AMF → Intel QSV → Apple VideoToolbox → CPU libx264

**依赖**：FFmpeg（系统安装）

---

### 05. 拆分为隔帧截图

**用途**：将视频按每秒 1 帧的频率提取 JPEG 截图，用于生成图像训练数据集。

| 脚本 | 功能 | 输入 | 输出 |
|------|------|------|------|
| `split.bat` | Windows 批处理：遍历目录下所有 MP4，每视频截图至独立文件夹 | 修改脚本中的 `input_folder` / `output_folder` 路径 | `frame_0001.jpg`, `frame_0002.jpg` ... |

**依赖**：FFmpeg（系统安装，需在 PATH 中）

---

### 06. 检查录制质量

**用途**：检测视频中的重复帧（与前一帧内容一致的帧），评估录制质量，生成分析报告和可视化图表。

| 脚本 | 功能 | 输入 | 输出 |
|------|------|------|------|
| `main.py` | 逐帧分析相似度，检测重复帧，生成统计图和 JSON 报告 | `python main.py <video.mp4> [options]` | 控制台报告 + PNG 统计图 + 可选 JSON |

**支持的相似度算法**：
| 方法 | 说明 | 适用场景 |
|------|------|----------|
| `exact` | 像素级精确匹配 | 检测完全静止的帧 |
| `mse` | 均方误差 | 检测轻微变化 |
| `hist` | HSV 直方图相关性 | 颜色变化检测 |
| `ssim` | 结构相似性 | 感知质量评估 |

**依赖**：OpenCV (`cv2`)， `numpy`， `matplotlib`，可选 `scikit-image`

## 快速开始

### 环境要求

- **Python 3.8+**
- **FFmpeg / FFprobe**（模块 02、03、04、05 需要，可通过 Homebrew 安装：`brew install ffmpeg`）
- **Python 依赖**（模块 01、06 需要）

```bash
# 安装 Python 依赖
cd "01.录制鼠标键盘输入"
pip install -r requirements.txt

cd "../06.检查录制质量"
pip install opencv-python numpy matplotlib
# 可选：pip install scikit-image
```

### 典型使用流程

```bash
# 1. 录制操作数据（与游戏同时运行）
python "01.录制鼠标键盘输入/input_recorder_cross_platform.py"

# 2. 将视频与日志匹配
python "02.匹配视频与日志/main.py" ./logs ./videos ./matched_videos

# 3. 压缩存储原始视频
python "03.视频压缩存储/video_processor.py"

# 4. 转码为训练用低码率视频
python "04.视频转码成低码率/main.py"

# 5. 提取帧截图（Windows）
# 修改 split.bat 中的路径后运行

# 6. 检查录制质量
python "06.检查录制质量/main.py" video.mp4 --method ssim --threshold 0.95
```

## 注意事项

1. **手柄录制**（模块 01）：macOS 需要在「系统设置 → 隐私与安全性 → 输入监听」中授予终端权限
2. **视频匹配**（模块 02）：视频文件名需遵循 `名称 YYYY.MM.DD - HH.MM.SS.cc.mp4` 格式
3. **硬件编码**（模块 03、04）：NVIDIA NVENC 需要相应的 GPU 和驱动支持
4. **跨平台**：`split.bat` 为 Windows 批处理脚本，其他模块为 Python 脚本，跨平台可用
