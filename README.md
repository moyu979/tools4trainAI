# tools4trainAI — AI 训练数据采集与预处理工具集

> ⚠️ **本项目中的代码尚未经过完整测试与调试（not debugged）**，可能存在未预期的错误。使用前请仔细核查各模块逻辑，建议在实际数据上验证后再投入正式使用。



## 概述

本仓库提供了一套完整的 AI 训练数据采集与预处理工具链，涵盖从游戏操作录制、视频匹配筛选、视频压缩存储、训练数据转码到质量检查的全流程。适用于需要采集游戏画面与操作数据作为 AI 训练素材的场景。

## 模块说明

### 01. 录制鼠标键盘输入

在游戏运行的同时，记录键盘、鼠标和手柄操作，生成带时间戳的日志文件。支持热插拔与"后连"。

> 日志格式、降噪参数、映射表、权限与反作弊警告详见 → **[01/README.md](01.录制鼠标键盘输入/README.md)**

---

### 02. 匹配视频与日志

将录制的游戏视频与对应操作日志进行时间匹配并对齐裁剪，按对齐开始时间成对命名输出。
含两个方案：`main.py`（单对单·任意开始，按时间区间重叠匹配）与
`main_hotkey.py`（多对多·录制热键，按日志中的录制开始快捷键 Alt+F9 / Ctrl+Shift+E 定位对齐）。

> 匹配逻辑与用法详见 → **[02/README.md](02.匹配视频与日志/README.md)**

---

### 03. 视频压缩存储

对大码率原始视频进行压缩归档，节省存储空间（码率 ≤ 50Mbps 直接复制，否则 HEVC 硬件编码）。

> 压缩参数与用法详见 → **[03/README.md](03.视频压缩存储/README.md)**

---

### 04. 视频转码成训练低分辨率

批量转码为 AI 训练可用的低码率格式（高度 640 等比例缩放），自动检测并选用最优硬件编码器。

> 编码器检测优先级与用法详见 → **[04/README.md](04.视频转码成训练低分辨率/README.md)**

---

### 05. 拆分为隔帧截图

将视频按每秒 1 帧的频率提取 JPEG 截图，用于生成图像训练数据集。

> 用法详见 → **[05/README.md](05.拆分为隔帧截图/README.md)**

---

### 06. 检查录制质量

检测视频中的重复帧，评估录制质量，生成分析报告和可视化图表。

> 相似度算法与用法详见 → **[06/README.md](06.检查录制质量/README.md)**

## 快速开始

### 环境要求

- **Python 3.8+**
- **FFmpeg / FFprobe**（模块 02、03、04、05 需要，可通过 Homebrew 安装：`brew install ffmpeg`）
- **Python 依赖**（模块 01、06 需要）

```bash
# 安装 Python 依赖
cd "01.录制鼠标键盘输入"
pip install -r requirements.txt

cd "../06.检查录制质量"
pip install opencv-python numpy matplotlib
# 可选：pip install scikit-image
```

### 典型使用流程

```bash
# 1. 录制操作数据（与游戏同时运行）— 统一记录器（键盘+鼠标+手柄）
python "01.录制鼠标键盘输入/record.py"

# 2. 将视频与日志匹配（单对单·任意开始；多对多·录制热键用 main_hotkey.py）
python "02.匹配视频与日志/main.py" ./logs ./videos ./matched_videos

# 3. 压缩存储原始视频
python "03.视频压缩存储/video_processor.py"

# 4. 转码为训练用低码率视频
python "04.视频转码成训练低分辨率/main.py"

# 5. 提取帧截图（Windows）
# 修改 split.bat 中的路径后运行

# 6. 检查录制质量
python "06.检查录制质量/main.py" video.mp4 --method ssim --threshold 0.95
```

## 注意事项

- **模块 01**：macOS 需在「系统设置 → 隐私与安全性 → 输入监听」中授予终端权限；注意反作弊检测风险（详见 [01/README](01.录制鼠标键盘输入/README.md)）
- **模块 02**：视频文件名需遵循 `名称 YYYY.MM.DD - HH.MM.SS.cc.mp4` 格式
- **模块 03/04**：硬件编码需要对应的 GPU 和驱动支持
- **模块 05**：`split.bat` 为 Windows 批处理脚本
