# 05. 检查录制质量

## 用途

检测视频中的重复帧（与前一帧内容一致的帧），评估录制质量，生成分析报告和可视化图表。

## 使用方式

```bash
python main.py <video.mp4> [options]
```

输出：控制台报告 + PNG 统计图 + 可选 JSON。

## 支持的相似度算法

| 方法 | 说明 | 适用场景 |
|------|------|----------|
| `exact` | 像素级精确匹配 | 检测完全静止的帧 |
| `mse` | 均方误差 | 检测轻微变化 |
| `hist` | HSV 直方图相关性 | 颜色变化检测 |
| `ssim` | 结构相似性 | 感知质量评估 |

## 依赖

- OpenCV (`cv2`)
- `numpy`
- `matplotlib`
- 可选 `scikit-image`
